THE PROJECT

A learning project
built around history.

This site demonstrates a complete supervised learning flow: inspect passenger records, prepare mixed numeric and categorical data, train a classifier, and expose the result through a small web app.

The included CSV has 891 passenger records. The model learns associations in those records; it does not recreate every circumstance aboard the ship or explain why any individual lived or died.

What happens after you press predict?

Each step is performed by the Python API. The same preprocessing pipeline is used for training and new passenger inputs.

What does the percentage mean?

It is the model's estimated probability for the submitted feature profile under this fitted classifier. It is not a guarantee or a historical identity match.

Can I compare it to model accuracy?

Not directly. This version fits the model on all 891 rows for the interactive demo. To report performance, create a separate stratified train/validation split and evaluate on records withheld from training.

Why are some columns excluded?

alive duplicates the answer, so using it would leak the target. class duplicates pclass; the unnamed index is not a passenger trait; and some derived columns overlap other inputs.

Is the ship picture archival?

No. The hero uses generated illustrative artwork of a Titanic-style ocean liner. It is not presented as a historical photograph.
