ABOUT THE PROJECT

A small model,
a piece of history.

This interactive demo uses the Titanic passenger dataset to practice a supervised machine learning workflow. A Logistic Regression model learns patterns in ticket class, sex, age, family size, fare, and embarkation town.

Missing numeric values are filled with the training data median, missing categories with the most common value, and categories are encoded before prediction. The result is an estimate from historical patterns, not a certainty.
