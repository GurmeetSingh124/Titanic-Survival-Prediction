FIELD GUIDE

What does each column mean?

The model uses six selected inputs. Other fields describe the data but may duplicate the answer or add little useful information.

TARGET

survived

Outcome: 1 means survived; 0 means did not survive.

MODEL INPUT

pclass

Ticket class: first, second, or third.

MODEL INPUT

sex

Passenger sex category recorded in the data.

MODEL INPUT

age

Passenger age in years; some records have no age.

DERIVED INPUT

family_size

Siblings/spouses and parents/children, plus the passenger.

MODEL INPUT

fare

The recorded ticket fare.

MODEL INPUT

embarked

Boarding port: Southampton, Cherbourg, or Queenstown.

EXCLUDED

alive

A text duplicate of the answer, so it would reveal the target.

NOT USED

class · deck · cabin

Duplicate or highly incomplete fields left out of this simple model.

MACHINE-LEARNING FLOW

How a prediction is made.

The website uses the saved preprocessing and model pipeline when a new example profile is submitted.

STEP 01

Load the data

Read the passenger CSV and inspect its fields and outcome.

STEP 02

Prepare inputs

Fill missing values, encode categories, and derive family size.

STEP 03

Train the model

STEP 04

TOOLS AND TECHNOLOGY

Python + pandas

HTML, CSS, JavaScript

Build the responsive page, charts, and interactions.

Jupyter Notebook

Document EDA, feature engineering, and model training.

Joblib

Save and load the trained model pipeline.

PROJECT LIMITS

A probability is an estimate.

It reflects patterns learned from limited historical records and the fields entered. It is not a guarantee or an explanation of any individual's outcome. This is an educational demo, not a tool for real-world decisions.
