FIELD GUIDE

What each column means.

The raw file includes useful fields and a few duplicate/derived columns. The model only uses its six selected inputs.

TARGET

survived

Outcome label: 1 means survived, 0 means did not survive.

MODEL INPUT

pclass

Ticket class: 1st, 2nd, or 3rd. A rough indicator of fare class.

MODEL INPUT

sex

Recorded passenger sex category: male or female.

MODEL INPUT

age

Passenger age in years. Some records have no age recorded.

DERIVED INPUT

sibsp + parch

Combined to make family size: siblings/spouses plus parents/children, including the passenger.

MODEL INPUT

fare

Ticket fare recorded for the passenger.

MODEL INPUT

embarked

Boarding port: S Southampton, C Cherbourg, or Q Queenstown.

EXCLUDED

alive

Text duplicate of the target outcome. Excluded to prevent target leakage.

EXCLUDED

class

Text form of pclass. Excluded from the model because pclass already carries the same information.

NOT USED

deck

Cabin deck, missing for most passengers in this file.

NOT USED

who · adult_male · alone

Convenience/derived fields. They overlap information already represented by other inputs.

NOT USED

Unnamed column

A row index included in the CSV, not a passenger characteristic.
